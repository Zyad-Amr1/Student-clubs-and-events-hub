# Student Clubs & Events Hub (CampusConnect)

An Android university project for discovering student clubs and events, managing event approvals, reserving seats, and handling event waiting lists.

## Project status

**Clean restart — Sprint 0 (planning and setup).** The previous Week 4 assignment files have been archived in the Git branch `backup/old-week4-assignment`. No application implementation is present on `main` yet.

## Planned technology stack

- **Android application:** Flutter (Dart)
- **Backend API:** Python, FastAPI
- **Database:** PostgreSQL
- **Project management:** Jira (Scrum)
- **Version control and CI:** GitHub and GitHub Actions

## Mandatory MVP scope

1. Club pages with descriptions and upcoming approved events.
2. Club administrator event creation and Student Affairs event approval.
3. Student RSVP with capacity enforcement and FIFO waiting list, including automatic promotion when a confirmed reservation is cancelled.
4. A personal My Events calendar for students.
