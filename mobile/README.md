# CampusConnect — Flutter Android app

Flutter is the approved mobile framework. This folder is a setup placeholder — **not a generated or runnable Flutter project yet**.

After Flutter SDK and Android tooling are installed on the development machine, generate the application in this directory from the repository root:

```bash
flutter create --platforms=android --project-name campusconnect mobile
cd mobile
flutter doctor
flutter run
```

Commit the generated Flutter project through a feature branch / pull request, without overwriting teammates' files.

Initial student bottom navigation will be Home, Clubs, Calendar, Profile.
Authentication screens and REST integration belong to the AUTH Stories.
